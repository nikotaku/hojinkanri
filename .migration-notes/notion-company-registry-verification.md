# Notion法人一覧移行の検証記録

## 実施範囲

移行元はNotionワークスペース KC の「法人一覧」データソース（`collection://294533e0-ae8c-4a56-9a61-ef998342ed30`）である。2026年9月14日時点で、28法人および60プロパティを抽出し、法人名で現行Supabaseの28法人と全件照合した。法人番号、代表者名、設立年月日、資本金、法人設立届、着金目標日、ホームページ、既存サービスの状況を所定の法人管理項目に移行した。

加えて、Notion固有の項目は法人ごとの追加台帳として保存した。関連レコードについては、参照URLだけでなく、取得できた名称・属性をスナップショットとして保存している。各法人詳細の「移行済み追加情報」では、移行元の値を分類別に確認・編集できる。

## 追加調査と本文移行

Notionページ本文を全28法人について確認し、空ページを除く23法人の本文・埋め込みデータベース情報を追加台帳に移行した。取得可能だった埋め込みテーブルの16レコードも保存済みである。これには、銀行リスト、共有リスト、銀行関連の進捗・口座情報などが含まれる。Notion MCPから参照できなかったTasksデータベースは、データソースの参照情報を残し、取得不能であった事実を記録した。

| 検証対象 | 結果 |
|---|---:|
| 法人一覧との照合 | 28法人すべて一致 |
| 追加台帳項目 | 497件 |
| ページ本文スナップショット | 23法人 |
| 本文の埋め込みレコード | 16件 |
| 書類プロパティ | 43件 |
| 書類のファイルメタデータ | 48件 |

## 書類ファイルの取扱い

Notionの保護ファイルURLにはサーバーから直接アクセスできず、HTTP 403を確認した。このため、48件の書類については、ファイル名と元の参照情報を法人管理の追加台帳に保存している。NotionへログインしたMy Browserでページ本体にアクセスできることも確認したが、ブラウザ自動化では保護された各ファイルの一括ダウンロードを行えない。

この制約を解消するため、書類項目ごとに「ファイルを移行」操作を追加した。Notionから一度ダウンロードしたファイルをこの操作でアップロードすると、法人管理のSupabase Storageに保存され、以後はNotionを参照せずに開ける。アップロード先のストレージバケットは既存の公開設定を確認済みであり、1回に最大20ファイル、1ファイル25MBまで受け付ける。

## アプリケーション検証

`npm run typecheck`、`npm run build`、`git diff --check`を実行し、すべて成功した。株式会社Forwardの法人詳細ページでは、代表者名、法人番号、設立年月日、法人設立届、サービス・審査状況、関連レコード、書類名、登録・連絡先、基本情報編集フォームが表示されることを確認した。
